# Smart Expense Manager 💰

A simple and responsive web application for tracking income, expenses, and monthly budgets.

## 📌 About the Project

Smart Expense Manager helps users keep track of their personal finances in one place. Users can add income and expenses, categorize transactions, monitor their balance, and see how much of their monthly budget has been used.

The current version is a frontend-based application that stores transaction data locally in the browser.

## ✨ Features

* Add income and expenses
* Categorize transactions
* Track total income
* Track total expenses
* Calculate current balance
* Set and monitor a monthly budget
* Display remaining budget
* View recent transactions
* Smart budget usage insights
* Data persistence using browser Local Storage
* Responsive design for desktop and mobile devices

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Local Storage

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Start adding your income and expenses.

No server or installation is required for the current version.

## 📊 How It Works

The application calculates:

**Balance**

```text
Total Income - Total Expenses
```

**Budget Remaining**

```text
Monthly Budget - Total Expenses
```

The application also provides a simple spending insight based on the percentage of the monthly budget that has been used.
